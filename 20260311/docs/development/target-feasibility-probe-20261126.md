# 目标板数可行性核查：封闭板界未提供额外提前排除

2026-11-26。按用户同意的范围验证“以少一张板为目标，提前停止不可能达标的补全”。形成了可运行的私有原型、数学判断、合成测试和保存状态投影。**封闭板剩余空间界在181条已完成、几何不同的保存序列上，没有一次比单纯板数上限更早排除；停止这版增强界，不接入生产搜索，不扩大实验。**

工厂口径保持不考虑纹理、修边5毫米、刀径6毫米及现有0/90度旋转。受限前缀、确定性补全、强基线及暂停新增排序启发式的约束保持。生产算法、配置、原始数据及Word主稿未改。

## 三个具体判断

设每张板修边后的包络可用面积为C，全部零件包络总面积为A，目标板数为T。包络仍按当前宽高分别增加刀径构造，不把留缝计入产品净利用率。

### 普通剩余面积检查不区分前缀

前缀已放包络面积P、剩余面积R满足P+R=A。当前打开b张板，若把全部未占面积都视为可用，则剩余容量为`(bC-P)+(T-b)C=TC-P`。必要条件`R≤TC-P`化简为`A≤TC`，与前缀无关。

所以普通面积下界可作一次性检查，不能据此宣称有了布局反馈或前缀筛选机制。本次三单的包络面积下界为26、90、345，均未直接否定目标27、94、370。

### 已打开板数是一个可靠的截断条件

当前`decode`只在原板上追加零件或开新板，没有合并/删除已打开板、移动已放零件的操作。因而`b>T`时，这条解码路径不可能达到目标。这只是当前无重排解码器路径的判断，不是整个装箱问题不可行的证明。

也不能把它无条件称为原算法完整评分的等价优化：若当前最好板数为B、目标为B-1，在打开第B张板时截断，会舍弃可能改善同B张次级评分的候选。本轮没有更改词典序评分或宣称这两种政策等价。

### 原型增加“封闭板浪费”下界

若一张现有板的每个MaxRects自由矩形都容不下任何剩余许可朝向，则该板在当前无重排解码器下不能再接收零件。后续自由矩形只会分裂为子矩形，剩余类型只会减少，因此不会重新变得可放。

记这些板未被包络占据的总面积为W，则必要板数下界为：

`LB=max(b,ceil((A+W)/C))`。

本原型仅计整张板已无法接收余件时的损失，不推断仍开放板上的局部孔洞全部不可用。面积按原0.1毫米精度转整数计算；**不相加可能重叠的MaxRects自由矩形面积**。剩余朝向采用二维Pareto极小集合保留“至少有一种可放”的判断；仅在该集合改变时重查未变的板，否则只检查刚发生放置的板。

## 已固定的验证范围

使用已有保存结果的178件82种、739件86种、2416件13种完整几何序列，共181条；不新增候选、不运行工厂订单解码或搜索。不同行为批次只投影各自的状态，不混用其历史计时。投影只按顺序插入当时已保存的坐标；判断只使用当前状态及已知余件几何，不读取未来坐标。

主要目标固定为当前已知强基线少一张：27、94、370。另检查各原始共同初解少一张的目标28、95、371，其中有10条已达标保存见证，均未被错误排除。这些是事后状态诊断，不把已知基线结果注入新搜索的初解或当作新发现。

普通面积与开板位置先做了探索性读取，随后在封闭板界的工业投影结果出现前固定私有协议。额外提前量的工程筛选条件是：2416件相对普通开板上限的中位提前量至少5个百分点，且无正确性违反。该条件只是本候选的投入筛选规则，不是统计显著性、论文或学位标准；此次实际额外提前量为0，未调低条件或增加更强孔洞规则来挽救结果。

## 正确性与实现复核

原型初始9项测试通过后才执行工业保存状态投影。随后追加2项参考检查，共**11项通过**：包含自由矩形重叠反例、旋转/容差、源精度、未来坐标独立性、合成枚举和对真实解码器各步状态的朴素参考比较。两个测试组分别枚举三组四件的全部24种排列，使用真实解码器验证；这些合成调用不计作工厂新实验。

两个6×6零件装入10×10板的正例表明：普通面积界为1，放入第一个零件后封闭板界已能证明至少2张，早于开出第二张板。因此工业投影的零增益不是原型只能退化为板数上限的结果。

工业投影在禁止构造求解器、解码及搜索的环境中执行；从原始CSV重新核对181份保存布局的完整身份、尺寸、朝向、边界/包络、摘要及评分。投影中未出现后续又进入已判封闭板的情况，所有逐步下界均不大于已知可行最终板数。独立读取UID→板号及序列重算所有开板触发位置。跨旧739批次使用前，核对六个自由矩形初始化/分裂/包含/裁剪函数的AST与当前源码一致。

65份冻结源代码、测试、输入、原始CSV、原型和Word主稿哈希保持不变。现有生产回归**440通过、3项既有可选CutEval集成跳过**，原因仍是依赖仓库有未提交修改。没有独立代理复审、远程CI或实体加工声明。

## 文献机制与决定

- [Sparrow，2025，第4节](https://arxiv.org/html/2509.13329v1)：已有将排样优化转为固定目标尺寸可行性问题的框架；它允许临时重叠并移动几何，本项目的固定解码器单调截断与之不同。
- [Martello与Vigo，1998](https://pubsonline.informs.org/doi/abs/10.1287/mnsc.44.3.388)：出版商摘要明确已有下界用于二维装箱分支限界的基础。本轮仅据摘要确认框架，不移植其具体下界到当前可旋转问题。
- [Fontan与Libralesso，2020，第3节](https://arxiv.org/html/2004.02603v2)：已有部分解占用面积、废料及其引导函数。其断头切割状态与当前MaxRects状态不同，不声称公式逐项等价。

据这些基础，单独使用“少一张板目标”“分支限界”或“浪费面积记账”不足以证明独立创新；本轮也没有完成封闭板公式的全面新颖性核查。更直接的否决依据是：**已实现的增强界没有提供额外提前排除，未通过事先固定的投入条件。**

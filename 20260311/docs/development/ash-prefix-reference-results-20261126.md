2026-11-26。**本轮未建立现有前缀的独有评价效率优势，也未刷新已知最少板数。** ASH在CLASS04更早省板；CLASS07的1000次评价组中，ASH三个种子和简单两件扫描均达到27张，5秒组均未省板。固定ASH为后续必比参照，不恢复旧复杂搜索或继续追加静态评分。主题仍为受限前缀。

## 实现和冻结范围

执行前[协议](ash-prefix-reference-protocol-20261126.md)已随代码提交冻结，运行版本`ca0e7b8c370e620866ee6665b75d77f7d7a5e57a`。新增独立模块`inrp.ash_sequence`和按需调用的`inrp.sequence_reference`，默认求解器及注册表未改。代码没有写入UID7/87或给定省板见证。

[Oliveira、Gamboa与Silva（2021）](https://link.springer.com/chapter/10.1007/978-3-030-85476-8_8)的算法1–2及参数段已有本地全文，作为本次序列策略来源：逐位置从剩余队列首项开始，随机拒绝时循环向后扫描；接受并移除后再开始下一个输出位置。α初值0.1，每个非改进完整提案加0.002，上限0.65；严格减少板数时更新基序列并重置α，同板次级评分不更新策略基序列。

本次有两处明确移植：使用我们的公共解码器，以及共同Greedy＋短边强初解，替代原论文构造器与原始初始化。称为**ASH序列策略参照**，不是完整ASH复现、最新最强算法或新方法。所有臂使用同一全局词典序挑选最终布局，但ASH的自适应更新只看板数。

只运行已暴露的CLASS03、04、07三个公开配置，各100件，固定方向、零修边和零刀缝。**CLASS03与CLASS04的零件尺寸清单相同，板规格分别为40×40与100×100；它们不是两个独立订单。** CLASS07为100×100。工厂“不考虑纹理、修边5、刀径6”的口径不变，本轮没有工厂搜索，不能把公开零刀缝利用率写成工厂结果。

SINGLE保留现有早期候选次序；PAIR按真实UID有序二元组的字典序扫描；两者余件均以同一短边顺序补全。ASH从相同强初解出发生成全局排列。每臂均冷启动并自行支付两次公共初解，全部候选从空布局完整重放，保留相同解码器的正常臂内缓存；仅跳过已经评价的完全相同UID序列。ASH三个种子1000/1001/1002；两个确定性扫描各运行一次并共享为参照，不把它们重复算成三个独立样本。

30次运行按冻结随机次序完成：3配置×2预算制度×（2确定性扫描＋3个ASH种子）。每次单独启动工作进程，不重跑、不改候选、不调参。

## 研究决策

本轮完成了此前缺失的直接文献参照，但没有建立新算法贡献。K2相对K1在CLASS07的表达增量依旧成立；现有全局序列方法同样可以达到27张，所以不能以这一见证单独支持前缀独有优势。ASH与PAIR的表达范围不同，本对照也不是相同两件范围内的选择器消融。

将ASH纳入后续强参照；受限前缀若要成为方法贡献，需要一个明确机制，并在同两件范围简单扫描及这类既有序列策略之外证明同成本增量。本轮不把ASH改名为我们的创新，不继续试权重、不恢复旧PUCT、不追加工厂矩阵，也不将三种已知且部分共享尺寸清单的配置写成独立泛化验证。

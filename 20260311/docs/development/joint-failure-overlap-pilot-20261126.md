# 缺件类型重合评分：受限两件前缀的单例机制预试验

2026-11-26。接续[创新边界与目标反馈诊断](innovation-scope-feedback-diagnostic-20261126.md)。**本轮得到一个可执行候选及单例评价效率信号：计入全部单件探测后，三个冻结种子的类型重合访问均在256次评价上限内到达已知27张目标。** 不代表新的最好利用率、工业收益、跨实例优势或创新已经成立。

## 具体机制

此前只按单件未放件面积评分，不能清楚提示已知联合成员。本轮保留每个单件前置u在固定目标容量内的未放件类型计数`E_u(t)`，按下式优先访问两件前缀：

`g(u,v) = sum_t area(t) * min(E_u(t), E_v(t))`，越小越先访问。

直觉是先检验两个单件试探的失败是否不同，而不要求两个单件各自都改善面积评分。该交集运算不作数学原创主张；它是代理排序，**不是可行性下界、真实依赖判定或安全剪枝**。g=0不保证组合成功。其对称性也不能证明正反前缀的布局等价；有序候选均保留。所有并列使用冻结随机次序，不用已知UID选有利顺序，不附加权重。

当前只处理本公开案例的固定方向宽高类型；同形零件按数量计算，身份仍用于序列、缓存隔离和最终完整性。没有新增形状排序、阻塞件修复、PUCT或跨板几何动作。每个候选仍是`P ++ H(其余)`，前缀最多两件。

## 离线筛查与选择偏差

复用上一轮保存的100份单件反馈，仅计算代理分数，不运行排样。9900个有序对去掉100个已属于K1完整词的别名，剩9800个新增K2完整词。最佳层g=0共1998个，占20.39%，包含已知(7,87)及倒序。

本地协议在本轮新分数出现前规定：最佳层不超过25%且包含已知正控制才值得做最小对照。**门槛依赖已知答案，属于暴露案例上的开发筛查，不是独立验证或外部预注册。** 4.90倍只是优先层相对候选池的规模比，不是实测提速或预测准确率；正反控制也不是两个独立样本。

## 最小在线对照

仅使用已暴露的CLASS07：100件、100×100板、固定方向、零修边/刀缝。各组实际重放同一Greedy与短边H初解并精确核对旧布局，两者均28张，目标固定27张。之后统一使用目标容量扫描：放不进27张板的件记为未放并继续后件；只有全部交付且几何通过才算达到目标。每条候选均为空布局、空解码器，不使用免费历史单件反馈。

四种策略：

- OVERLAP：在线扫描全部100个单件，再按g访问两件。
- AREA：同样支付100条单件扫描，按两个单件未放件面积之和访问两件，用于检查类型信息相对标量的增量。
- RANDOM：直接打乱有序两件候选，不强迫支付不需要的单件探测。
- LEX：沿用现有PAIR的有序UID升序访问，不支付单件探测。

总评价启动上限256，包括两次普通初解、全部单件反馈和两件评价；失败或超时不退额度。每次目标扫描处理100件。随机组种子1000/1001/1002，LEX确定性只运行一次，共10次。全部随机策略先打乱同一个完整有序对表，反馈组再稳定排序；精确完整序列已评价后去重。直接组没有免费得到完整K1无增益结论，队列9899；反馈组支付探测后为9800。

每次30秒总上限、搜索截止27秒、3秒收尾，父进程35秒看门；找到首个完整27张解即停。候选生成/排序、探测、验证、日志写出和退出均计成本。实际所有运行在额度或目标条件下退出，未发生超时/补跑。

## 与文献的关系及一项更正

- [GDRR](https://doi.org/10.1016/j.ejor.2021.11.031)已有目标容量、不完整解和缺件面积评价。本候选在受限序列族中使用跨单件反馈的类型计数交集排序两件，不能把借用的基础重新主张为原创。
- [排列链接学习pbELL/HLL](https://ir.cwi.nl/pub/31039/31039.pdf)已有变量依赖探测。补读完整第3节后更正私有早期协议的一句描述：pbELL是把一对基因调为相邻、交换前后各做一次适应度评价，初始化全对检测计n(n−1)次；“扰动后局部优化”属于3LO，不能混称pbELL。冻结原文及更正保留，实验没有pbELL组，故无对其胜负结论。
- 本候选获取n份单件反馈后做廉价交集排序，不具有pbELL的依赖检验性质；评价信息、动作空间、保证及成本不同。**这些差异与本单例正结果仍不足以证明新颖性。** 目前未完成专门针对失败集合互补选择的全面近邻审查。

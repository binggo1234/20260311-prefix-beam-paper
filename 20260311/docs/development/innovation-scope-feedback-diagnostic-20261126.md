2026-11-26，接续[定向文献决策](mechanism-literature-decision-20261126.md)。用户关心的是如何形成自己的研究贡献，而不是再换一个算法名称。本轮新增隔离诊断，没有接入生产搜索或运行工厂订单。

后续：[缺件类型重合预试验](joint-failure-overlap-pilot-20261126.md)已给出一个具体候选及暴露单例的效率正信号。下文“具体新机制仍未形成”记录的是本诊断当时状态，不代表后续候选已通过新颖性或泛化验收。

**决定：目标板数与未放件面积保留为已有思想参照；不直接把“按单件缺件面积排序，再组合前缀”作为新主方法。** 研究问题继续限定为硬前缀预算下的联合选择，但具体新机制仍未形成。不能将这个研究问题本身写成创新点。

## 什么可以借，什么必须由我们证明

已有思想可以作为新方法的基础。需要明确借用部分，再提出一个能够描述、实现、与最近方法区分的新增机制，并证明它解决具体困难。单纯用在家具数据、叠加多个已有模块或使用一个新名称，均不足以说明算法创新。适配工程可以有价值，但不能替代目前缺少的独立机制与增益证据。

| 层次 | 当前证据与处置 |
| --- | --- |
| 少一张板目标、允许内部不完整解、缺件面积反馈 | GDRR已有；作为评价参照，不单独主张创新 |
| 短前缀加固定补全 | 已有优先级决策向量可表示；硬限制是研究条件，不自动构成原创表示 |
| 联合变量选择、学习变量依赖 | 排列链接学习已有；不能仅改称“交互感知前缀”就主张新方法 |
| 本项目尚需解决的问题 | 少量昂贵评价下，如何发现单件评分不优的联合前缀收益，并转化为完整省板解 |
| 可接受的候选贡献 | 必须有具体探测/选择规则及成本界定，明确区别于已有序列、链接学习与局部修复，再在强参照下检验省板或达到相同省板的成本 |

本轮补查的[排列混合链接学习，GECCO Companion 2021](https://doi.org/10.1145/3449726.3463152)已提出排列经验链接学习，并将其与统计链接结合；作者稿第2.3节还讨论条件依赖。因此，“考虑联合效应”“考虑上下文”都只能描述研究目的，不能单独充当新机制。已取得[作者机构PDF](https://ir.cwi.nl/pub/31039/31039.pdf)，核对摘要、第2.1–2.4节及第3节开头，未复现算法。Crossref原始元数据及全文仅留本地。

## 新做的小诊断

对象是已参与开发的公开CLASS07：100件、100×100板、固定方向、零修边和刀缝。工厂的无纹理限制、修边5、刀径6口径不变，本轮没有工厂新实验。已知事实是H、单件7、单件87均28张，而两件(7,87)及倒序均27张。这些是旧见证，本轮不计新省板发现。

在读取新结果前冻结私有协议。目标固定T=27；使用真实解码器、每条序列全新实例。从头扫描完整序列：若某件只能开第28张板，丢弃该后继并记为未放件，继续后件；其他放置保留。当前解码器词典序总是优先可行旧板，故这种拒绝操作符合本诊断的容量限制。它改变失败后的转移语义，与普通完整解码模式分开；没有修改默认解码器。

运行H、全部100个单件前缀、两个给定两件前缀，共103次目标容量扫描、10300次逐件decode；另做一次T=28的H容量控制。两个给定两件序列只作已知正控制，不参与选择或调整参数。全部完成，执行器记录的写出前耗时约2.04秒，非生产搜索提速对照，也未据此作评价效率主张。

单件按未放件净面积从小到大排名，保留全部并列，不用UID择有利名次：

| 给定前缀 | 未放件UID | 未放件面积 | 在100个单件中的名次区间 |
| --- | --- | ---: | --- |
| H | 30 | 975 | 不参与单件排名；与最优单件分数相同 |
| (7) | 52、10 | 1318 | 48–55；47件严格更优、8件并列含自身 |
| (87) | 30 | 975 | 1–47；47件并列含自身 |
| (7,87) | 无 | 0 | 已知完整27张正控制，不参与单件排名 |
| (87,7) | 无 | 0 | 已知完整27张正控制，不参与单件排名 |

100个单件产生15种不同的未放件面积，没有一个达到零缺件。信号并非恒定，但它不清楚地标出这两个已知联合成员：87没有相对H的单件分数增益，7的分数甚至更差。按单件分数只保留最优一档会排除7；若按分数阈值纳入7并保留全部并列，需要保留55个候选。这里没有预设或调优top-k，也没有运行这些候选之间的两件矩阵。

**本例说明：单件缺件面积的改善不是这组联合收益的必要条件。** 它不说明所有好组合都必须包含7和87，也不证明其他组合、条件式反馈或GDRR式完整搜索无效。已知答案的后验诊断不能当作泛化测试或搜索成功率。

## 验证与实际进度

- 私有诊断的8项合成检查通过：失败后继续放小件、零目标、足够容量与普通重放一致、目标调用隔离及非法身份/目标。先观察实现缺失时失败，再实现并运行全部私有测试。
- 独立只读审计104份保存记录，不调用求解器，重算身份分区、尺寸/固定朝向、边界、不重叠、未放件面积及排名。T=28控制和两个27张已知控制精确匹配旧布局。
- 协议、原型、测试在结果前的哈希锁定保持；1922份受保护生产/配置/测试等跟踪文件及Word主稿哈希不变。未运行生产算法回归，因为生产代码未改；不引用历史回归为本轮测试。
- 本轮没有新增工业利用率提升，没有提出已证实的新算法，也没有完成全面新颖性审查。

## 下一步的明确范围

把“目标容量评价”留作参照接口，停止直接依赖单件缺件面积优选首件的方案。继续暂停新增排序启发式、阻塞件规则与PUCT调参。首选研究任务是**联合收益的低成本识别**：规则必须允许本例这种单件评分变差却有联合收益的情况，同时说明探测了哪些候选、耗掉多少真实评价，以及如何保持硬前缀限制。

这仍是任务定义，不能提前写成算法。下一项机制必须同时给出：

1. 可执行的候选探测和扩展规则，不能只写“交互感知”或“自适应”。
2. 与排列链接学习、BubbleSearch/ASH和已停用尾件阻塞规则的逐项差异；若只剩参数和名称差异，归为已有方法适配。
3. 同解码器、同初解、同前缀候选族下的简单两件访问参照；把探测、失败及部分评价成本全部计入，同工作量和同总时间分别比较。
4. 材料验收只认全部零件交付后的省板/净利用率，或达到同等省板所需成本更低。内部评分下降、选中已知UID或扩大搜索空间不单独通过。

本轮不追加上述组合矩阵、不调整权重挽救单件评分、不把公开已用算例称未见数据。若无法给出这四项，就不把GDRR思想适配扩展成一轮完整主方法开发。主题保持受限前缀，但应继续诚实记录第2章的方法缺口。

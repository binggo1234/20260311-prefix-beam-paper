# 冻结反馈机制的跨公开实例验证

2026-11-26，用户明确授权：固定直接随机两件为强参照，在未参与机制选择的公开算例上检验反馈真实增量；不调窗口、权重，主题保持受限前缀。

## 研究问题与样本

比较冻结的STREAM_OVERLAP、STREAM_RANDOM和DIRECT_RANDOM。它们的policy.py与上轮逐字节相同，M=16、每条反馈最多2次联合尝试、哈希破同分及虚拟Fisher–Yates均不改；不运行其他新机制。目标是跨实例验证，不以改动后某个开发种子的正例充当结论。

样本在求解前固定为2DPackLib CLASS全部10类各100件的第02实例：cl_01_100_02至cl_10_100_02。不按初解、下界、历史成绩或本轮结果挑选、替换、补充。原压缩包SHA256为9f5ca94d6a9ee5c9273302b8fbddf028c3f6a1d595e80622aafe79ec55589f9c。保留每个成员原始板材尺寸（含10×10、30×30、40×40、300×300等），固定方向，0修边/刀缝；工厂无纹理限制、修边5、刀径6完全不变，工厂本轮不运行。

机制开发记录只使用第01个CLASS07，前QA文本检索未发现上述02名称。另在首次求解前对比全部10个第01实例及已有公开实例的整个几何多重集/尺寸指纹，包括旋转不变的保守检查。43个既有实例中，能绑定板材者比较完整指纹；缺少有限板材高度的条带实例另比较零件多重集，不能假定其板材尺寸。若发现与机制开发案重合则本批不得宣称其未参与选择；不读取成绩来替换病例。这里主张的是未参与本机制选择，不是从未接触CLASS数据家族、盲法或全球未见。

10个实例是跨实例单位；每例3个算法种子是重复访问路径，不当作30个独立实例。仅描述性比较，不以本筛查声称统计显著性、总体最优或创新成立。

## 一致实现和费用

每次实际冷重放现有baseline_sequence和short_edge_sequence两个初解，来自生产共同初解同一排序函数；各策略/种子源数据、两个初解完整序列/布局/评分必须相同。目标T=min(两初解板数)−1，H固定短边序列。各候选均为空布局/空解码器，同一已有目标容量扫描，深度<=2，不变更放置策略或允许几何修复。普通初解只排除已知完整路径，不供应缺件反馈。

统一总评价启动上限256，含2初解及所有单件探测、失败、两件扫描。每次30秒总上限，搜索27秒、3秒收尾，父级35秒看门；父进程生命周期<30秒作保守验证，不跨进程相减绝对时钟。找到全部交付且几何合格的<=T张方案即停；不继续尝试第二次降板。未达按额度/时间删失，不填257、不只取成功组均值。

公共必要条件：本批零留缝整型尺寸，若总净面积A>T*W*H，则目标数学上不可行，三组均在同样两次初解后停止，记area_bound_reject。这些实例保留在完整样本和最终板数表中，另列为无目标搜索机会，不算算法失败，也不计入可搜索组的成功率分母。此规则在看到初解前冻结，不据此更换实例或新增更强界。

每例种子1000/1001/1002，三组各一次，共90次。调度种子20261126：先打乱10例，再对每例每个种子的三组顺序独立打乱，完整区组串行执行。所有组都并发于同一批次时间段，不使用旧结果充当新参照；只读输入审核可以在求解前做，不读取新标签调整方法。不得补跑失败、加时、增种子或停止到看起来有利为止。

## 报告及处置规则

首先核准90次执行/源数据/共同初解/几何和费用；不合格运行不能伪装成有效平局或方法失败，整例比较资格单列。主要指标为同额度和总时限下最终完整解板数、净利用率、相对DIRECT_RANDOM的逐例及逐种子胜平负、总板数；同时对STREAM_RANDOM作反馈消融。报告各例三个种子平均板数和整体总板数，但30个种子结果不伪装30个实例。

次指标：目标达成次数、包含全部探测的首次达标累计评价及完结历时。共同成功子集的评价数胜平负另列，不能以该子集掩盖更多未达；两组均未达不能据内部缺件面积排名宣称材料收益。全样本整体利用率采用各例净面积/实际板材总面积，不能把不同板材尺寸的板数相加后乘同一板面积；并另报逐例利用率。三种子重复订单不当作一次真实工厂订单节材。

若相对直接随机没有净省板且跨实例胜负不占优，又没有在相同成功覆盖下出现至少两个不同实例支持的评价效率增量，则本冻结反馈版本不通过推进条件；若只优于同窗口而不优于直接随机，也不能宣称端到端增量。正信号只进入进一步机制/新颖性审查，不自动接入生产。负结果不外推为全部受限前缀或所有反馈无效。

## 实现计划与验证

只新增公开数据适配及运行/审计脚本于本地QA，不改冻结policy.py、目标扫描器、默认算法或主稿。先测官方格式解析、非100板材尺寸、请求/原成员一致性和区组完整性，再冻结所有依赖/输入/策略哈希后执行。运行后无求解器审计完整身份/几何、源成员、全部访问次序/费用/停止、共同初解一致、固定策略和主稿哈希；独立复审后公开报告和90次聚合，不上传第三方压缩包或原始工厂数据。

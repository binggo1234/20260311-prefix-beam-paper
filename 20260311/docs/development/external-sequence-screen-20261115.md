# 外部CLASS算例筛查：30次有效运行，材料结果全部持平

日期：2026-11-15。延续[739件订单的同期对照](sequence-neighborhood-results-20261115.md)，本轮完成了项目新引入公开实例的固定预算筛查。**简单单件前缀相对每例最强参照为0胜、10平、0负，未通过预定继续筛查门槛。** 没有新增主方法、启发式或生产求解器改动。

## 先纠正验证数据的判断

此前提出从现有生产数据中选未参与开发的订单，核对历史清单后发现这个前提不成立。当前10个批次、27份任务、39,267片板件均有历史用途：旧六任务6份、旧批次同源任务1份、既有开发任务9份、已打开过验证的任务11份。当前原始CSV哈希与2026-08-28盘点清单全部一致。**本地这批生产数据中没有可以重新命名为全新工业未见集的任务。**

因此本轮使用[博洛尼亚大学维护的2DPackLib官方CLASS数据](https://site.unibo.it/operations-research/en/research/2dpacklib)，不把旧生产订单重跑作为独立验证。CLASS出自Berkey–Wang及Martello–Vigo的二维装箱算例。所核对的项目既有公开实验涉及BENG/OKP/WANG及旧binpacktwo族，未发现本轮CLASS实例的执行记录；另与现有43份binpacktwo实例比对，未发现保留重复数量的有向或旋转不变整单尺寸清单重合。这是有明确本地核对范围的项目新公开算例筛查，不声称这些数据在全世界或所有历史副本中都未被使用。

## 执行前固定的范围与判据

固定选择CLASS的全部10类，各取100件、重复编号01，即`cl_01_100_01`至`cl_10_100_01`。选择没有使用本轮排样结果。下载官方CLASS.zip的SHA-256为`9f5ca94d6a9ee5c9273302b8fbddf028c3f6a1d595e80622aafe79ec55589f9c`。保留原始板材和零件尺寸，按原始行序保持身份与重复数量；本轮文件均为单件需求，转换器拒绝不支持的需求。

这是单独标记的**固定方向、零修边、零刀缝**标准几何比较。它不改变工业2440×1220毫米、5毫米修边、6毫米刀具包络设置，也不与那套利用率合并，不以本轮数字声称制造收益或复现文献最优算法。

每例均执行SINGLE / INSERT / KENDALL-E一次，沿用前轮已验证的生成器、共同Greedy→短边初解、精确UID序列去重及独立保存结果审计器，仅适配公开请求的板材、旋转、留缝和输出目录。每次仍为12个新完整序列的重放尝试、10000个完整提案上限、30秒全流水线、3秒收尾、38秒父进程上限且包含清理。缓存命中仍消耗重放额度，初始化两次另列但计入时间。

用计划种子20261116随机排列实例顺序及每例方法顺序，固定算法种子1000，共30次独立进程串行运行。首次运行前冻结请求、原始压缩成员、转换CSV、实现及传递依赖、源代码、协议、环境和801份历史JSON的哈希。没有重跑、替代实例、追加种子、修改访问次序或根据表现提前停止。

主要描述性比较是每例q12时的SINGLE板数减去`min(INSERT,KENDALL-E)`。**预定继续筛查门槛为30次全部有效、至少3例严格获胜且0例落败。** 这是本研究的投入筛查规则，不是统计显著性、创新成立、发表或毕业标准。未通过则不把固定单件排序升级为已有普遍优势的主方法，也不以负结果为由叠加启发式。

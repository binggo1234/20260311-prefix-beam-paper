# 80%严格省板目标：当前基序修正不能承担主方法

2026-11-27。用户指出3胜24平的覆盖面不足，要求探索至少80%的胜率。本轮只核查已有工厂结果与目标口径，没有新增排样、算法、实验矩阵或默认配置修改。

## 当前结果如何定位

[全批基序对照](factory-anchor-cohort-results-20261127.md)相对原短边单件参照为3/27严格省板，胜率11.1111%，净少3张、汇总净利用率增加0.050611个百分点。这是有效的局部基线修正，不能承担“对多数工厂订单有效”的主方法主张，标准基序选择本身也不作为独立创新。

逐单核查显示，仅F04、F15、F18改变了补全基序；其余24单的候选序列规则和UID访问次序不变。实际完成次数会受时限影响，但这24单没有新增算法候选内容。因此这项条件性基序修正没有覆盖多数订单的机制，继续只调它无法支撑80%的算法省板主张。不能将3个改变基序的订单另取分母，写成满足目标的100%胜率。

## 后续目标固定口径

- 完整27个工厂任务保留。至少80%严格省板，意味着至少22单获胜。
- 后续主方法应与已确认的固定强初解基序单件参照INITIAL比较；相同订单、尺寸、解码器、初始化、预算规则，最终完整用板数严格更少才计胜，平局不计胜。
- 同时要求全批净用板数下降、汇总净利用率提高、全部零件几何有效；实际评价覆盖、时间删失和失败继续完整报告。
- 这是用户提出的新探索目标，不回改旧实验协议、原数字或其有限结论，也不承诺尚未证实的22单提升能够实现。

原CSV、现有包络/修边模型的只读面积核查目前只证明F23的一件任务最低1张，已达到最优；其余26单界未闭合。该26单的未知界差不证明能够省板，F23仍保留在27单分母中。

## 工作去留

固定当前基序修正为强基线，停止围绕它追加变体来充当主方法。下一项试验必须改变平局订单的候选内容，并保持受限前缀主题及既有长度上限；已提出的强基序两件前缀对照具有更广作用范围，但增益及80%目标都尚未验证。首先寻找可核验的省板见证和覆盖面证据，再决定是否值得扩大完整矩阵、开发新选择机制；不预先把标准两件访问称为创新。

新增启发式、窗口/权重调参、尾件＋最小阻塞件规则继续暂停。本轮不为了目标重新选样、改预算或换较弱基线。默认算法和Word主稿未改。
